# Petal Reader: Read Markdown Aloud

Listen to any Markdown file **in preview mode**. Petal Reader reads only what the preview shows, never the `#`, `**` or `[]()` behind it.

## What you get

- **A small player in the bottom-right corner of the preview**: play/pause, back/forward 30 seconds, stop, and the elapsed and total time.
- **Word-by-word highlighting.** The spoken word glows yellow and the sentence is softly tinted.
- **Double-click any word** to start reading from exactly there.
- **A time bar with chapter marks.** Every heading (`#`, `##`, `###`) is a mark on the bar. Hover a mark to see its name and start time, then drag or scroll to move through the file.
- **Voice, speed (0.5×–2×), chapters list and options** behind the settings (sliders) button.
- **A compact mode.** The ⌄ button shrinks the player to a small play button and the time left.
- Code blocks are skipped by default; you can switch them on.

## How to use

1. Open a `.md` file.
2. Click the **▶ circle** icon at the top right of the editor (or press `Ctrl+Shift+V` for the normal preview).
3. Press the gradient **▶** button in the bottom-right corner of the preview, or double-click a word.

| Shortcut (preview focused) | Action |
| --- | --- |
| `Ctrl+Enter` | Play / pause |
| `Ctrl+[` / `Ctrl+]` | Back / forward 30 seconds |
| `Esc` | Pause |
| Arrow keys on the time bar | Back / forward 5 seconds |

## Want a more human voice?

VS Code can only use the voices installed on your computer, and those can sound robotic. Click the **speaker icon** at the top right of the editor (**Open in Petal Reader**). It opens the same file in Microsoft Edge, which has free “Natural” voices with the same highlighting, chapters and double-click jumping. Natural voices need an internet connection.

## Privacy

Everything runs locally. Nothing is uploaded unless you choose an online voice; online voices send the text being read to the voice provider (Microsoft or Google).
